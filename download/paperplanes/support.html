纸上猜飞机帮助

Wi-Fi 联机时，两台设备先接入同一个 Wi-Fi 或手机热点。房间未找到时，在加入方输入房主屏幕上的局域网地址和端口。若路由器限制设备互访，可以改用蓝牙。

蓝牙联机时，请允许附近设备权限和系统的可发现请求。在两台设备上比对应用显示的数字，再分别确认。应用尝试在 60 秒内恢复短暂断线。系统结束进程后，双方可以重新建房开局。

Support

For Wi-Fi play, first connect both devices to the same Wi-Fi or phone hotspot. If discovery fails, enter the host address and port shown on their phone. Use Bluetooth if the router restricts communication between devices.

Grant the relevant system Bluetooth permissions and compare the code displayed on both screens before confirming. The app attempts to restore a dropped link for up to 60 seconds. If the system closes the app process, open a new room.
