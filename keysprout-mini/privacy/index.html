4. 保留方式与保存失败

每类完成记录最多保留最近 1000 条，并受每类约 1.5 MB 的压缩数据预算限制；错键详情较多时，保留条数可能更少。为满足预算会移除最旧记录并显示提示。成长统计由当前保留的键盘事件课程记录计算，不是永久保存的终身累计。

设置和教程进度没有按日自动到期规则；草稿通常保留至本课完成、从头练、被更新、用户清除或失效校验清理。微信或系统清理也可能移除数据。当前没有开发者端备份或跨设备恢复功能。

如果读取或保存失败，小程序会提示错误；尚未保存的草稿或结果可暂留运行内存，供重试保存或明确放弃。如果存储始终未写入成功，强制关闭、系统结束进程或设备重启可能丢失这些未保存内容。 已有旧草稿可能只能恢复到上一次成功保存的位置。清理旧分片失败时，部分旧副本可能暂留本机，小程序会提示清理异常。

如需清除包括设置和教程在内的全部本地数据，请由监护人使用当前微信及设备提供的小程序数据／存储管理功能；具体入口和移除小程序是否同时删除存储，以当前客户端为准。系统清理、清除微信数据等操作也可能造成丢失，请谨慎操作。

开发者没有当前本地记录的远程副本，无法远程找回或代您清除设备记录。您可以停止使用小程序；如需帮助，可联系支持邮箱，无须为此发送练习记录或儿童身份资料。

Weixin / WeChat, the device system, web hosting and email services have their own data practices.

2. The current implementation

Lessons, graphics and audio are bundled. Developer code requires no account and includes no advertising, payment, analytics or tracking SDK. There is no developer server, practice-record upload, cloud synchronization, public sharing or leaderboard feature. Practice does not require sending the developer a child's name, birth date, school, photo or contact information.

Developer code does not call login or profile / phone-number interfaces, or request camera, microphone, location, contacts or photo-library access. The Mini Program still runs through Weixin / WeChat. Initial loading, updates and platform services may use the network. The absence of a developer upload feature does not mean the platform or operating system processes no data.

3. Local data and purposes

Persistent data below is written to the Mini Program's local storage on the current device. It restores preferences, resumes practice and displays local learning results. Current developer code does not upload it.

Keyboard-event lessons, keyboard-event reviews and mobile / tablet text practice are stored separately. Text input cannot reliably establish physical-keyboard use, so it does not count toward keyboard-event lesson qualification. A round using on-screen demo keys does not save a completed score; an unfinished demo can still save a position draft, and the tutorial remembers demo-key use.

Live input text, recent self-check input and key state, the parent arithmetic question and answer, and focus state are runtime data. Developer code does not retain a complete timestamped keystroke log or record input from other apps. Runtime platform type, window dimensions, safe areas, display pixel ratio, keyboard height and timing information are used to choose input mode, adapt the layout, draw and measure practice time. They are not persisted or uploaded as a separate device profile.

4. Retention and failed saves

Each completed-result category retains up to its most recent 1,000 results, subject to an approximately 1.5 MB compact-data budget per category. Detailed mistakes can reduce that number. Oldest records are removed to meet the budget, with a notice. Progress statistics use retained keyboard-event lesson records; they are not a permanent lifetime total.

Preferences and tutorial progress have no automatic expiry after a fixed number of days. Drafts normally remain until completion, restarting from the beginning, replacement, user clearing or invalid-draft cleanup. Platform or system cleanup can also remove data. There is no developer-side backup or cross-device recovery feature.

Read or save failures produce an error message. Unsaved drafts or results may remain in memory for retry or explicit discard. If storage never succeeds, force-closing, process termination or a device restart may lose that unsaved content. An older draft may recover only the last successful checkpoint. Failed cleanup can leave older local chunks or copies temporarily; the Mini Program reports a cleanup warning.

5. Viewing, clearing and stopping use

Recent results appear in Progress; unfinished practice can be resumed from lessons. After separate confirmation, Parent center's Clear local practice records removes lesson, review and text results, mistake details and both draft types. Preferences, practice length and tutorial progress remain. Clearing cannot be undone. A storage or cleanup error must not be treated as proof that every copy was removed; resolve the issue and retry.

To clear all local data, including preferences and the tutorial, a guardian can use the Mini Program data / storage controls offered by the current Weixin / WeChat client and device. Exact controls, and whether removing a Mini Program also removes storage, depend on that client. System cleanup or clearing Weixin / WeChat data may also cause loss; use those controls carefully.

The developer has no remote copy of these local records and cannot remotely recover or clear them. You may stop using the Mini Program. Support is available by email without requiring practice records or a child's identity information.

6. Children and guardians

KeySprout recommends ages 7–12 with a guardian's help, in sessions of 5–10 minutes, emphasizing finger placement and accuracy. The parent arithmetic entry only reduces accidental access. It does not verify identity, guardianship or legal consent, and is not a device-level child lock. Other users of a shared device may see local records; guardians should manage device access.

A guardian can contact the confirmed address about unsuitable content or inadvertently submitted child information. Operator details, applicable regional children's-data rules and handling arrangements still require verification before formal release; this draft does not replace that work.
